# 100xzone

A small static site with a downloadable file shelf and a separate Puppf explainer page.

- [Main page](index.html): lists a file link to `https://dl.100xzone.com/rr.jpg` and explains how downloads work.
- [Puppf page](puppf/index.html): a project explainer page.
- [Cloudflare Workers configuration](wrangler.jsonc): serves assets from this repository's root.

The linked `rr.jpg` is hosted on the separate `dl.100xzone.com` address; it is not present in this repository. This README describes the checked-in files and does not verify the live domain or deployment.
